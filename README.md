# Tem de Tudo - Aplicativo de Cadastro de Clientes

## Descrição

Exercício avaliativo.

## Funcionalidades

- **Tela de Boas-Vindas**: Apresenta a logomarca da loja e um botão para iniciar o cadastro.
- **Tela de Cadastro**: Permite que o cliente insira seu nome e finalize o cadastro.
- **Tela de Confirmação**: Exibe uma mensagem personalizada com o nome do cliente e a confirmação do cadastro.
- Navegação simples entre as 3 Activities:
  1. **MainActivity** - Tela inicial com a logomarca e o botão para iniciar o cadastro.
  2. **CadastroActivity** - Formulário onde o cliente insere seu nome.
  3. **ConfirmacaoActivity** - Exibe uma mensagem de boas-vindas com o nome do cliente.

## Tecnologias Utilizadas

- **Android Studio**: IDE para o desenvolvimento do app.
- **Java**: Linguagem de programação utilizada.
- **XML**: Para a definição dos layouts das Activities.
- **Android SDK**: Ferramentas para o desenvolvimento de apps Android.
